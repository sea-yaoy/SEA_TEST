# Nextjs Template

### Installation DEV

<!-- change API_URL in .env.development -->

```
yarn install
yarn build:dev
```

### Installation STAGING

<!-- change API_URL in .env.staging -->

```
yarn install
yarn build:stg
```

### Installation PRODUCT

<!-- change API_URL in .env.honban -->

```
yarn install
yarn build:pro
```
